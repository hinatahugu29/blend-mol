FAQ 1 — 対応 Blender バージョン
Question
Which Blender versions are supported?
Answer
Blend Mol is packaged as a Blender Extension and requires Blender 5.2 or newer. Earlier versions (Blender 4.x, 5.0, and 5.1) are not supported.

訳: Blender 5.2 以降（Extension 形式）が必要です。Blender 4.x / 5.0 / 5.1 には対応していません。

FAQ 2 — 外部ツールの要否
Question
Do I need to install Open Babel, RDKit, or any external Python packages?
Answer
No. Blend Mol has zero external dependencies. The 3D SMILES distance-geometry embedder, chemical file importers/exporters, and the UFF solver (with both a compiled Rust backend and a pure-Python fallback) are all self-contained inside the extension ZIP.

訳: 不要です。3D SMILES 生成、ファイル入出力、UFF ソルバー（Rust＋純 Python フォールバック）はすべて ZIP 内に完結しています。

FAQ 3 — 対応 OS（Windows / Linux / macOS）
Question
Which operating systems are supported?
Answer
Windows (x64) and Linux (x64) are verified in automated CI with Blender 5.2+ and include native Rust libraries (.dll / .so). A macOS Universal library (.dylib for Apple Silicon and Intel) is also included; however, the macOS native build is currently unsigned and awaiting real-world user feedback. If the native library cannot load on any system, Blend Mol automatically falls back to the built-in pure-Python UFF solver.

訳: Windows / Linux は Blender 5.2+ の CI で自動検証済み。macOS Universal (.dylib) も同梱していますが未署名・実機フィードバック待ちです（ロード不可時は純 Python へ自動フォールバック）。

FAQ 4 — 対応フォーマットと対応元素
Question
What file formats and elements are supported?
Answer
Import & Export: MDL MOL (V2000 and V3000), SDF (multi-record with data items), XYZ, and PDB, plus SMILES import (with 3D conformation generation, tetrahedral @/@@/@TH1/@TH2 and E/Z / \ stereo, isotopes, and aromatic Kekulization) and Partial UFF JSON report export. Currently 18 main-group elements are supported: H, C, N, O, F, P, S, Cl, Br, I, B, Si, Ge, Sn, As, Sb, Se, and Te.

訳: MOL (V2000/V3000)、SDF（複数レコード）、XYZ、PDB の入出力、SMILES 生成、UFF JSON 出力に対応。元素は主族 18 元素に対応。

FAQ 5 — Partial UFF の範囲と現在の制限
Question
What does "Partial UFF" mean, and are there any current limitations?
Answer
Blend Mol's Partial UFF evaluates five energy terms—bond stretch, angle bend, torsion, out-of-plane inversion, and van der Waals—and its energies have been cross-checked against Open Babel 3.1.1. In v0.1.92, electrostatic (Coulomb) interactions and transition metals are not included yet, and SMILES stereo tags for allene/square-planar/octahedral centers are not supported. Canceling Live UFF with Esc or right-click restores coordinates from the start of that Live UFF session.

訳: 結合伸縮・変角・二面角・面外・vdW の 5 項を計算（Open Babel 3.1.1 と照合済み）。静電項・遷移金属・特殊立体表記は未対応。Esc キャンセルはセッション開始時へ戻ります。

FAQ 6 — Auto Live UFF の水素明示化メッセージ
Question
Why does Auto Live UFF ask me to "make implicit hydrogens explicit first"?
Answer
Converting implicit hydrogens into editable explicit atoms rebuilds the molecule's mesh objects in Blender, which cannot be done safely while Blender's move operator (G) is actively holding an atom. Click the red "Make Hydrogens Explicit" button in the Atoms & Molecules panel once before dragging, or click "Start Live UFF" manually (which prepares hydrogens automatically).

訳: 水素明示化はオブジェクト再構築を伴うため、移動操作（G）中の自動開始では行いません。事前に赤いボタンを押すか、手動で Start Live UFF を押してください。
