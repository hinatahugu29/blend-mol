基本操作の流れ

操作場所: 3D Viewport → サイドバー（N）→ Blend Mol

1新しい分子を作る

  1. 原子を置きたい位置へ 3D カーソルを移動します。
  2. New Blend Mol Molecule を押します。
  3. 分子名、最初の元素、形式電荷を入力して確定します。

最初の原子が 3D カーソル位置に作成され、選択状態になります。

補足: SMILES から始める場合は、Import / Export を開いて Create from SMILES を使います。既存ファイルからなら MOL / XYZ / PDB / SDF の読み込みも使えます。

2原子と結合を追加する

対象の分子を選択した状態で、Edit Atoms & Bonds を開きます。

選択した原子に結合した新しい原子を追加する

  1. 結合の起点にしたい原子を選択します。
  2. 新しい原子を置く位置へ 3D カーソルを移動します。
  3. Element と Bond Order を選びます。
  4. Add Bonded Atom at 3D Cursor を押します。

新しい原子と、選択していた原子からの結合が同時に作成されます。NEW 選択原子が既に飽和していて通常なら結合を追加できない場合は、原子価が収まるまで選択原子の明示水素を自動的に（必要なら複数個）新しい原子へ置き換えます。手動で水素を削除しておく必要はありません。

原子だけを追加する

結合を作らずに原子だけを置くには、元素を選んで Add Atom at 3D Cursor を押します。後から次の手順で結合できます。

32つの原子を結合する

  1. 同じ分子内の原子を 2つだけ 選択します。複数選択は Shift を押しながらクリックします。
  2. Bond Order で単結合（1）、二重結合（2）、三重結合（3）を選びます。
  3. Create or Change Selected-Atom Bond を押します。

未結合の2原子なら結合を新規作成します。すでに結合済みなら、その結合次数を変更します。

注意: 原子価を超える結合は作成・変更できません。下部の Valence 表示も確認してください（この操作では明示水素の自動置換は行われません。先に対象原子の水素を手動で削除するか、Add Bonded Atom at 3D Cursor を使ってください）。

4結合・原子を変更・削除する

結合次数を変える

変更したい結合の両端の原子を2つ選び、Bond Order を変更してから Create or Change Selected-Atom Bond を押します。

結合を削除する

削除したい結合そのものを選択し、表示される Delete Selected Bond を押します。

原子を削除する

原子を選択して Delete Selected Atom を押します。その原子につながる結合も一緒に削除されます。NEW Shift クリックなどで複数の原子を選択していれば、選択中の原子をまとめて1回の操作で削除できます。

仕上げ

原子を Blender の移動ツールで動かした後は、Sync Edited Atom Positions を押して Blend Mol の分子データへ反映します。必要に応じて Relax Display Geometry または Minimize Partial UFF で形状を整えます。NEW UFF 系の操作（Minimize Partial UFF / Start Live UFF）は、暗黙水素が残っていても自動的に明示化してから計算するため、事前に Make Implicit Hydrogens Explicit を手動で実行しておく必要はありません。

Import / Export（読み込み・書き出し）

分子を読み込む、または選択中の分子を書き出すためのパネルです。

ボタン機能補足
MOLMDL MOL（V2000 / V3000）を読み込み原子、座標、結合情報を読み込みます。芳香族結合（次数 4）は単結合と二重結合に自動で割り当てます。割り当てられない場合は理由を表示して中止します。
XYZXYZ を読み込み原子座標を読み込みます。Perceive Bonds（既定で ON）で、原子間距離から単結合を自動で作ります。結合次数は推定しないので、二重結合などは手作業で設定します。暗黙水素は追加しません。
PDBPDB を読み込み原子座標と、ファイル内の CONECT による単結合を読み込みます。CONECT が1行もないファイルは、原子間距離から単結合を作ります（Perceive Bonds Without CONECT、既定で ON）。
SDFSDF を読み込みSD ファイルの全レコード（V2000 / V3000）を、1レコード1分子として読み込みます。Max Records（既定 100）、読めないレコードを飛ばす Skip Invalid Records、重ならないよう横に並べる Arrange in a Row を指定できます。各レコードのデータ項目（> <NAME> など）は分子に保存され、SDF 書き出し時に戻ります。
Create from SMILESSMILES から分子を作成SMILES と分子名を入力して作成します。基本有機 SMILES のサブセットに対応し、初期配置は簡易 2D レイアウトです。
MOL / XYZ / PDB / SDF（Export selected molecules）選択中の分子を書き出し原子・結合・分子ルートのいずれかを選択してから実行します。書き出し前に、Blender 上で動かした原子位置を自動同期します。MOL と SDF は Format で V2000 / V3000 / Auto（999 原子・結合を超えると V3000）を選べます。SDF は選択中のすべての分子を1つのファイルに書き出します。
Export Partial UFF ReportUFF の診断情報を JSON 出力原子型、実装済みのエネルギー項、拘束、固定原子、最終最小化・ベンチマークのログを保存します。

PDB の注意: PDB 出力は結合の有無を CONECT として保存しますが、結合次数と形式電荷は保存されません。

NEW Rebuild Selected Molecule ボタンは、このパネルから Display & Mesh Settings パネルへ移動しました（Atom Scale / Bond Radius / Show Implicit Hydrogens のすぐ下）。表示が崩れた場合や、ジオメトリ系の表示設定を既存の分子へ適用したい場合はそちらを使ってください。

Edit Atoms & Bonds（原子・結合編集）

分子を選択しているときに表示される、日常的な編集の中心です。

共通の入力欄

項目内容使われる操作

UFF Constraints（UFF 拘束）

Partial UFF の最小化中に、距離・角度・ねじれ角を目標値へ保つための拘束を設定します。

種類選択入力操作
Distance原子を2つTarget Distance (Å)、Constraint StrengthSet Target は入力値を使います。Use Current は現在の原子間距離を目標値として登録します。選択中の拘束だけ、または全拘束を削除できます。
Angle原子を3つ。アクティブ原子が中心Target Angle (°)、Angle StrengthSet Target／Use Current で登録または更新します。中央原子を最後に選択してアクティブにするのが要点です。
Dihedral結合で一続きの原子を4つTarget Dihedral (°)、Dihedral Strength曖昧でない4原子の結合経路を選択します。Use Current は現在のねじれ角を目標値にします。

Strength（強さ）: 大きいほど目標値を強く維持します。極端に大きい値は最小化を不安定にすることがあるため、まず既定値付近から試すのが安全です。

Partial UFF（力場最小化）

対応する原子型を持つ分子で、実装済みの UFF 項を使って構造を最小化するパネルです。原子型に問題がある場合は「Not ready for UFF」と理由が表示されます。

NEW Minimize Partial UFF と Start Live UFF は、実行対象の分子にまだ暗黙水素が残っていれば、計算の前に自動的に明示水素へ変換してから続行します。UFF は明示原子しか見ないため、以前は事前に Make Implicit Hydrogens Explicit を手動で実行しておく必要がありましたが、この手順は不要になりました。明示水素が既に揃っている分子では何も変化しません。

状態・エネルギー表示

表示／入力意味
Atom typing: readyUFF 用の原子型を割り当てられた状態です。型ごとの個数も表示されます。
Show Energy Breakdown結合伸縮、角度、ねじれ、面外、van der Waals の項別エネルギーを表示します。項によっては明示水素が必要です。
Partial UFF total実装済みの UFF 項の合計エネルギーです。静電項は含まれません。
UFF Iterations通常の最小化で試行する最大反復数です。
UFF Max Atom Step1 回の受理ステップで原子が動ける最大距離です。大きくしすぎると不安定になり得ます。
Gradient Tolerance / Energy Tolerance最小化の収束判定です。小さいほど厳密ですが、時間がかかる場合があります。
UFF OptimizerSteepest Descent（安定な基準法）、FIRE2（対話操作向け）、L-BFGS（最終収束向け）を選びます。
UFF Compute BackendAuto は Rust が利用可能なら Rust、なければ Python を使います。Rust はネイティブ DLL が必要です。

通常・対話型の操作

ボタン／設定必要な選択機能
Minimize Partial UFF対象分子分子全体を最小化します。失敗した場合は元の座標を保持します。実行後は前後の座標、エネルギー、反復数、終了理由が表示されます。
Show Before / Show After最小化履歴あり直近の最小化の前後座標を表示します。比較や復帰に使えます。
Start Live UFF / Stop Live UFF動かす原子を1つ選択選択原子の移動中、周辺を繰り返し緩和する対話モードを開始／停止します。NEW 計算中にエラー（collinear 等）が起きた場合は、ステータスバーへの表示に加えて、次に Live UFF を開始するまでこのパネル内にエラーメッセージが残り続けます。以前はエラーが起きても何も表示されず無言で停止していました。NEW 「原子を動かすと自動開始」中にエラーが起きた場合、同じ原子への自動再開始は 1.5 秒間控えられます（手動の Start Live UFF ボタンは対象外）。ドラッグ中・キャンセル・移動確定のたびにエラーが連発して操作を妨げないようにするためです。このエラーはステータスバー表示のみで、マウス直下にポップアップは出ません（出す場合、確定/キャンセル操作の前にポップアップを閉じるクリックが余分に必要になるため）。
Jitter All Atom PositionsNEW対象分子固定原子以外の全原子へ、Jitter Magnitude (Å)（既定 0.05 Å）までの小さなランダム変位を1回加えます。衝突（collinear）など、厳密に縮退した開始形状から抜け出す応急対応です。実行前に自動でスナップショットを保存するため、気に入らなければ Restore Position Snapshot で元に戻せます。
Relax Around Selected Atom動かした原子を1つ選択原子を一時的に固定し、周辺だけを少数ステップ緩和します。手動で原子を動かした直後の調整向けです。
Start Live UFF When Moving an Atom設定原子を動かすと Live UFF を自動開始し、落ち着いたら停止します。
Interactive UFF Steps設定手動の周辺緩和で実行するステップ数です。
Live Compute Budget / Live Update Interval / Maximum Settle Updates設定対話型 UFF の1回あたりの計算予算、更新間隔、移動後に落ち着くまでの最大更新回数を調整します。
Benchmark 1 UFF Step対象分子1 ステップの計算時間を測定し、推定更新周波数などを表示します。構造は変更しません。
